# Changelog

All notable changes to **kushal** (the human, not the editor — although the editor also) are documented here.
Format is calver — one release per school year. Pre-2022 builds were played on easy mode (elementary school).

## [2027.0-beta] — unreleased · graduating-year build

### Added
- co-prime minister module — 60-person student government, 1,500+ constituents
- co-leader instances: chess club, the good guys (both currently stable)
- `bcss-newspaper` reader polish — the paper renders at full sharpness in-browser
- certifications: harvard (cs50ai) · helsinki (full stack open) · imperial (math for ml)
- this portfolio — the IDE you're inside right now

### Deprecated
- **sleep schedule** — no longer maintained. use at own risk. removal planned post-graduation.
- `procrastination.exe` — marked deprecated after it achieved sentience

### Fixed
- "works on my machine" — now diagnosed across a 60-member team and 1,500+ users

### Known Issues
- imposter syndrome — reintroduced by running for co-prime minister. workaround: `git log`.
- calendar invites arrive in person now — the 1,500 users know where i sit
- `work-life balance` referenced but never defined (see Problems tab)
